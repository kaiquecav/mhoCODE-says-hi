## Why this matters

PLC engineers shouldn't have to learn version control to collaborate on
a project. mhoCODE makes versioning feel like the rest of the IDE:
clear buttons, plain language, and helpful explanations inline.

Two modes ship together:

- **Local mode** — a private, automatic history of your project on your
  machine. No accounts, no setup. Rewind anytime, branch experiments
  freely, go back to "the one that worked" in a couple of clicks.
- **Team mode** — branches, pull requests, and cloud sync for projects
  built with someone else. mhoCODE handles the plumbing; you focus on
  the logic.

Pick the mode that fits the project. Switching later is one click.
